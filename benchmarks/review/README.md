# Descriptive review of the recorded data

`recorded-dispersion.csv` is generated by `scripts/summarize_recorded.py` from the preserved raw CSV repetitions. It adds medians, extrema and sample SD without changing any original result. Use a new output path to regenerate. No statistical significance test or new hardware run is implied. The HBM 8 GiB copy case is capacity-confounded; do not interpret it as an ordinary tier-performance point.

The basic RAM write series spans two clusters; its mean alone does not describe either cluster well. Some inter-tier repetitions are also highly variable. Read all recorded repetitions rather than promoting a single mean as a technology ranking. Manual supplemental runs have incomplete provenance and are excluded from this aggregation.
